## 2026-10-26 디자인 수정
- 사용자 요청: 과한 장식과 자동 생성한 듯한 인상을 줄이고, 읽기 쉬운 산세리프 조합과 네이비·버건디·화이트를 사용한다. APK 재설치 없이 웹에서 모바일 화면을 확인한다.
- 화이트 배경, 네이비 기본 조작, 절제한 회색 안내문을 쓴다. 그라데이션·기울어진 장식 격자·영문 장식 문구·큰 그림자를 제거하고 테두리와 여백으로 구분한다. 잎 로고 대신 격자 아이콘을 사용한다.
- 홈은 이어하기·새 게임·오늘의 문제에 집중한다. 설명은 실제 동작을 짧게 알리며 기능·저장·무료 도움 정책은 유지한다.

## 색상·폰트 설정 위치
- [style.css](../../src/style.css)의 `:root`: 기본 네이비 `--navy: #293e5f`, 본문 `--ink: #26354b`, 보조 문구 `--muted: #687485`, 버건디 오류 `--error: #883e52`, 오류 배경 `--error-soft: #f8edf0`.
- [lobby.css](../../src/lobby.css): 홈·달력·통계의 여백, 경계와 모바일 높이별 배치. 작은 화면에서는 중복되는 요약만 감추고 하단 내 기록 메뉴를 유지한다.
- [fonts.css](../../src/fonts.css): Pretendard 400/500/600/700은 한글 설명·버튼·제목, Manrope variable 200–800은 보드·숫자판·시간·숫자 통계에 사용한다. 숫자 폰트에서도 한글은 Pretendard로 대체한다.
- 폰트는 로컬 WOFF2로 제공하며 외부 CDN 요청을 하지 않는다. APK 다음 빌드에도 같은 자산이 포함된다. [원본 출처·OFL 라이선스·해시](../../public/fonts/README.md), 전체 폰트 약 1.13MB. 원본 글꼴을 수정하지 않았다.

## 오류 표시
- 행·열·블록 중복은 관련 칸 모두 버건디로 표시한다.
- 중복이 없더라도 사용자가 입력한 숫자가 정답과 다르면 해당 칸을 버건디로 표시한다. 선택된 오류 칸은 같은 색 테두리를 추가한다.
- 색만으로 구분하지 않도록 `aria-invalid`와 칸의 접근성 이름에 `숫자 중복` 또는 `정답과 다름`을 제공한다. 올바른 숫자·지우기·되돌리기 후 현재 상태를 다시 계산한다. 게임 규칙·저장 형식·실수 횟수 규칙은 바꾸지 않는다.

## 설치 없는 모바일 미리보기
- [미리보기](https://kjk0189-boop.github.io/haru-sudoku/preview.html) / [일반 웹 게임](https://kjk0189-boop.github.io/haru-sudoku/).
- [public/preview.html](../../public/preview.html)은 실제 앱을 같은 출처 iframe으로 연다. PC에서는 약 390px 너비의 프레임, 휴대폰에서는 화면 전체를 사용한다. 홈·게임·기록·달력을 실제로 조작할 수 있다.
- 별도 가짜 UI나 게임 상태를 만들지 않는다. 기존 앱과 같은 코드·저장 경로를 쓰며 브라우저 새로고침으로 저장된 진행을 복원한다. PC 홈 상단 `모바일 화면 보기`로 접근한다.
- 웹 배포는 자동 갱신되지만, 이전에 설치한 APK는 재설치 전까지 기존 디자인이다. 이번 요청에서는 웹 검토 흐름을 우선하며 새 APK는 만들지 않았다.
