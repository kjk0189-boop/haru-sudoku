# 게임 완료 결과와 홈 이동

[목차](index.md) · [개인 기록](android-app.md) · [검증 기록](verification.md)

## 2026-10-26 요청
게임을 완성하면 결과 창에서 다음 다섯 항목을 확인하고 메인 화면으로 이동한다.

1. 게임 난이도
2. 게임 기록: 이번 시도의 완료 시간
3. 난이도별 최고 기록: 같은 난이도 완료 게임 중 가장 짧은 시간
4. 이번 시도의 힌트 사용 횟수
5. 같은 난이도의 완료 횟수

## 동작
- 마지막 숫자 입력과 힌트 완주 모두 자동으로 결과 창을 연다. 완료된 보드는 배경에서 조작할 수 없으며 타이머는 멈춘다.
- `메인 화면으로`를 누르면 기록을 보존하고 홈으로 이동한다. 닫기·Escape·Android 뒤로가기도 같은 경로를 사용한다. 자동 시간 제한으로 결과를 닫지는 않는다.
- 새 게임을 만들기 전 완료 결과를 먼저 표시하며, 모바일의 마지막 힌트 설명 패널보다 결과 창을 우선한다.
- 완료한 매일 도전을 다시 열면 동일한 결과를 볼 수 있다. 결과를 열거나 닫고 새로고침해도 완료 횟수가 늘지 않는다. 새 시도로 처음부터 다시 풀어 완주하면 별도 완료 기록으로 집계한다.
- 한국어·영어를 모두 지원한다. 모드와 매일 도전 날짜도 표시한다.

## 통계 기준과 구현
- [completion.ts](../../src/completion.ts)의 `getCompletionResult`가 결과를 계산한다. 방금 끝난 실행을 포함한 임시 프로필을 만들어 저장 effect가 실행되기 전에도 현재 완료가 빠지지 않게 한다. 원본 게임·프로필은 바꾸지 않는다.
- 실행 ID 중복 방지와 완료 기록 고정은 기존 `upsertRecord` 규칙을 따른다. 이미 완료로 저장된 게임의 시간·힌트 사용량은 기존 결과를 유지한다.
- 최고 기록·완료 횟수는 **같은 난이도의 클래식+매일 도전**을 합산하며 미완료·중단·다른 난이도는 제외한다. 최고 기록에도 이번 게임을 포함한다. 힌트 사용 여부로 기록을 제외하지 않는다.
- 기존 개인 기록 보관 한도(최대 500개)에 남아 있는 기록을 기준으로 한다. 저장 형식과 게임 규칙은 바꾸지 않는다.
- [App.tsx](../../src/App.tsx): 완료 감지·결과 우선순위·홈 이동·포커스와 키보드 처리를 연결한다. [style.css](../../src/style.css): `.completion-modal`, `.result-*` 배치와 작은 화면 처리.
- [completion.test.ts](../../tests/completion.test.ts): 첫 완료 즉시 포함, 난이도/모드 합산, 최단 시간, 저장 복원 중복 방지, 원본 불변성, 기존 완료 결과 고정 검증.

## 검증 범위
분리된 로컬 포트의 테스트 데이터로 마지막 칸 입력·힌트 완주·다섯 항목·홈 이동·중복 방지·완료한 매일 도전 재열기를 확인했다. [화면 증거](../assets/completion-result.png)는 실제 사용자 기록이 아닌 검증용 데이터다. 테스트 준비 페이지는 무시된 `artifacts/` 내부이며 공개 빌드나 Git에 포함하지 않는다.

실제 Android 설치·기기 뒤로가기는 연결 기기가 없어 미검증이다. 웹 브라우저의 Escape/닫기·홈 버튼은 검증했으며 네이티브 뒤로가기 경로는 코드를 검토했다. 전체 검사와 공개 배포 결과는 [검증 기록](verification.md)에 남긴다.
