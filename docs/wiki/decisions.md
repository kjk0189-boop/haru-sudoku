## ADR-001: 서버 없이 시작
- 상태: 채택 (2026-10-25)
- 구성: React + TypeScript + Vite, localStorage, GitHub Actions + Pages.
- 이유: 독립적인 싱글 플레이이므로 서버 운영 없이 배포 가능. 게임 규칙을 UI에서 분리해 테스트한다.
- 한계: 브라우저 데이터 삭제 시 기록 소실. 여러 기기 간 공유 불가. 클라이언트에 정답이 있으므로 경쟁 기록의 공정성을 보장하지 않는다.
- 근거: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Vite 배포](https://vite.dev/guide/static-deploy.html#github-pages).

## ADR-002: 위키를 저장소 안에 유지
- 상태: 채택 (사용자 요구, 2026-10-25)
- 별도 GitHub Wiki 대신 docs/wiki를 사용한다. 코드와 문서 변경이 한 커밋에 남고 LLM이 로컬에서 읽을 수 있다.
- 작업 단위로 커밋하며 제품·설계·검증·남은 일을 링크로 연결한다.

## ADR-003: 검증한 문제 묶음
- 상태: 신규 게임은 ADR-005로 대체. 기존 저장 복원용 목록은 유지.
- 실시간 생성 대신 고정 문제를 제공하고 유일해 검사로 품질을 보장한다.
- 난이도는 초기 분류이며 인간 풀이 기법으로 정밀 검증하기 전까지 잠정값으로 표시한다.
- 힌트는 설명할 수 있는 논리적 단일 후보를 우선한다. 발견하지 못하면 답을 임의로 공개하지 않고 그 한계를 안내한다.

## ADR-004: 플레이 편의와 힌트 정책 분리
- 상태: 채택 (사용자 요구, 2026-10-25)
- 중복 표시를 끌 수 없게 하고, 9개 채운 숫자는 고정 위치의 빈자리로 대체해 입력판 이동을 막는다. 키보드 입력에도 동일 규칙을 적용한다.
- 고급 메모는 현재 보드 기준 후보의 일괄 교체다. 수동 메모를 보존하려면 되돌리기를 사용한다. 한 동작은 한 이력으로 저장한다.
- 힌트 제한은 [policy.ts](../../src/policy.ts)에서 정하고 [session.ts](../../src/session.ts)에서 강제한다. UI 비활성화 외에도 상태 함수에서 제한한다.
- 모든 난이도의 초기 제한은 null(무제한). 실제 칸을 채웠을 때만 차감하고 undo로 환불하지 않는다. 사용량은 기존 저장 형식으로 복원한다.
- 상세 요구사항과 설정 예시는 [변경 이력](changes.md)을 따른다.

## ADR-005: 네 단계 논리 평가와 브라우저 자동 생성
- 상태: 채택 (사용자 승인, 2026-10-25)
- 입문을 제외한 쉬움·보통·어려움·전문가로 제공한다. 기본 기법의 부담 점수와 후보 제거·X-Wing을 고정 순서로 평가한다.
- 새 정답판·단서 배치를 생성한 뒤 유일해와 논리 완주, 요청 등급, 정답 일치를 검사한다. 최근 80개와 현재 문제의 정확한 중복을 제외한다.
- UI 지연을 피하기 위해 Worker 사용. 제한 시간 실패 시 다른 등급을 내지 않고 현재 게임을 유지한다.
- 생성 문제 스냅샷·풀이 증거를 저장하며, 기존 저장 자료는 보존한다. 모르는 기법이 필요한 문제는 제공 대상에서 제외한다.
- [정확한 수식·동작·제약](difficulty.md), [생성 실측](generation-audit.json), [코드 그래프](code-map.md).

## ADR-006: 모바일 플레이와 부가 기능 분리
- 상태: 채택 (사용자 승인, 2026-10-25)
- 600px 이하에서는 한 화면의 보드·도구·숫자판을 우선한다. 부가 작업은 더보기, 긴 설명은 하단 패널로 연다.
- 동적 뷰포트와 안전 영역을 고려하고 최소 보드 아래로 화면이 작아지면 스크롤을 허용해 접근 가능한 내용을 보존한다.
- 패널은 타이머 정지·배경 inert·포커스 복원을 공유한다. 모바일과 PC에서 같은 상태 변경 함수를 사용해 동작 차이를 줄인다.
- [배치와 검증 범위](mobile-layout.md).

## ADR-007: 홈·게임 분리와 오프라인 개인 APK
- 상태: 채택 (사용자 요청, 2026-10-26). 유료 스토어 등록 이전 개인 APK로 사용성을 확인한다.
- Capacitor로 기존 웹 규칙·Worker를 재사용하고 자산을 내장한다. 홈/매일 도전/기록과 집중 플레이를 분리한다.
- 기록은 실행 ID 단위로 완료를 고정하고, 날짜 도전은 한국 날짜 고정 시드를 사용한다. 서버·로그인은 추가하지 않는다.
- 도움은 무료 기본값과 미래 정책 판단을 분리한다. 광고나 재화 보상은 실제 제공 전까지 활성화하지 않는다.
- [저장 한도·설치·제약](android-app.md).
