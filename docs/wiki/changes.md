## 2026-10-25 / 플레이 편의 기능 개선

### 요청과 반영
1. 중복 숫자 표시를 항상 활성화: 설정 토글 제거, 행·열·상자의 충돌을 색상과 접근성 속성으로 표시.
2. 입력 완료 숫자 숨김: 고정 숫자와 사용자 입력을 합쳐 9개 이상이면 숫자 버튼을 숨긴다. 버튼 자리는 유지해 다른 숫자의 위치가 바뀌지 않게 한다. 키보드와 상태 함수도 추가 입력을 막는다. 지우기·되돌리기 후 9개 미만이면 버튼이 돌아온다.
3. 고급 메모: 현재 입력을 기준으로 모든 빈칸의 합법적인 후보를 한 번에 채운다. 기존 수동 메모를 교체하며 한 번 되돌리면 이전 메모가 복원된다. 자동 추적 모드는 아니므로 입력 후 다시 누르면 갱신된다. 중복이 있으면 먼저 수정을 안내한다.
4. 난이도별 힌트 정책: 현재 세 난이도 모두 무제한. 제한값을 설정하면 잔여 횟수 표시와 소진 시 차단이 작동한다. 성공한 힌트만 사용량에 포함하며 되돌리기로 사용량을 환불하지 않는다.

### 코드와 설정
- [화면 및 입력](../../src/App.tsx)
- [상태 규칙](../../src/session.ts): `completedDigits`, `fillAllNotes`, `remainingHints`, `applyHint`
- [힌트 설정](../../src/policy.ts): `HINT_LIMITS`의 `null`은 무제한, 0은 사용 불가, 양의 정수는 게임당 제한.
- 예: `{ easy: 5, medium: 3, hard: 1 }`로 바꾸고 재배포하면 제한 활성화. 현재 저장된 게임의 사용량에도 적용한다. 새 게임과 재시작은 사용량을 초기화한다.
- 기존 v1 저장 형식을 그대로 읽는다. 힌트 사용량·메모·이력 저장을 유지한다.
