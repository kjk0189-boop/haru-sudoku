# 제품 기획

[위키 목차](index.md) · [설계 결정](decisions.md)

## 목적
회원가입 없이 모바일과 PC에서 바로 즐기는 한국어 스도쿠. 가칭 ‘하루 스도쿠’. 차분한 초록색과 종이색 배경, 큰 입력 버튼을 사용한다.

## 첫 버전
- 검증한 9×9 문제 자동 생성과 네 난이도 (쉬움·보통·어려움·전문가)
- 숫자 입력, 지우기, 후보 메모, 실행 취소, 강조
- 타이머, 일시정지, 새 게임, 다시 풀기
- 브라우저 자동 저장과 이어하기
- 항상 켜진 충돌 표시, 기본 논리 힌트, 완성 확인
- 완료 숫자 숨김과 입력 차단, 모든 후보를 채우는 고급 메모
- 난이도별 힌트 제한 정책 (현재는 모두 무제한)
- 모바일 대응과 키보드 조작

## 후속 범위
일일 도전, 실제 플레이 기반 난이도 보정, 문제 미리 생성, 개인 통계, 다크 모드. 로그인·기기 간 동기화·순위표·대전은 서버가 필요해 별도 단계로 둔다.

## 출시 기준
문제의 유일해, 정답 검증, 저장 복원 및 손상 데이터 처리, 실행 취소, 고정 칸 보호, 모바일 조작, 실제 배포 경로를 확인한다. 확인 전에는 해당 항목을 완료로 쓰지 않는다.
