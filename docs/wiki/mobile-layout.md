# 모바일 한 화면 플레이

[목차](index.md) · [변경 이력](changes.md) · [검증](verification.md)

## 2026-10-25 / 사용자 승인
모바일에서 보드와 숫자 입력을 위해 스크롤하지 않도록 핵심 플레이를 한 화면에 배치한다. 자주 쓰는 기능은 직접 누르고 부가 기능은 더보기와 하단 패널에서 연다.

## 배치
- 화면 너비 600px 이하: 소개 문구·PC 키보드 안내·하단 소개 영역을 숨긴다.
- 상단: 작은 브랜드와 더보기, 보드 위 난이도·타이머·일시정지.
- 중앙: 보드와 진행 칸 수.
- 아래: 되돌리기·지우기·수동 메모·자동 메모·정답 확인의 5개 도구와 9개 숫자판.
- 마지막 한 줄: 진행 메시지. 긴 문장은 생략 표시하고 누르면 전체 내용을 읽을 수 있다.
- 더보기: 새 게임 난이도 선택·시작, 같은 문제 재시작, 게임 안내, 플레이 가이드, 자동 저장 상태와 힌트 사용량.
- 정답 확인: 기존 논리 힌트 기능을 실행한 후 설명을 하단 패널로 표시한다. 확인하면 보드로 돌아온다.
- 데스크톱: 기존 소개와 우측 조작 영역을 유지한다.

## 크기와 예외
보드 폭은 `min(100vw - 32px, max(252px, 100dvh - 312px - 상하 안전 영역))`로 계산한다. `viewport-fit=cover`와 `safe-area-inset-*`를 사용한다.
페이지 전체를 강제로 자르지 않는다. 기본 글자 크기에서 주요 세로 화면은 스크롤 없이 맞추고, 아주 낮은 화면에서는 최소 보드 크기를 유지하면서 문서 스크롤을 허용한다. 안내와 메뉴의 긴 내용은 패널 내부에서 스크롤할 수 있다.

## 패널 동작과 접근성
- 메뉴·힌트·안내·확인창을 읽는 동안 게임 타이머를 멈춘다.
- 패널이 열린 동안 배경은 inert로 처리하고 배경 스크롤을 잠근다.
- Tab/Shift+Tab은 패널 안에 머물고 Escape나 닫기 버튼으로 닫는다.
- 메뉴 → 새 게임 확인/안내 전환에서도 최초 버튼을 기억한다. 닫으면 그 버튼으로 돌아오며, 완료로 비활성화되거나 화면 전환으로 숨겨졌으면 더보기·보드·PC 안내 순으로 사용할 수 있는 대상을 찾는다.
- 새 게임 취소는 보드와 입력을 보존한다. 기존 저장 형식, 난이도 평가, 문제 생성, 힌트 제한 정책은 변경하지 않는다.

## 근거와 검증 범위
[기본 화면](../assets/mobile-play-2026-10-25.png) · [메뉴](../assets/mobile-menu-2026-10-25.png)

320×568, 375×667, 390×700, 390×844, 430×932에서 문서 높이가 뷰포트 높이와 같고 숫자판이 화면 안에 있음을 실제 브라우저로 확인했다. 320×480에서는 560px 문서로 스크롤을 허용해 하단이 잘리지 않게 했다.
실제 휴대폰·Safari·OS 글자 확대는 해당 환경이 없어 미검증이며, 위 숫자는 데스크톱 브라우저의 뷰포트 검사다.
