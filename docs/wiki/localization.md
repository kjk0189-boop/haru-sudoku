## 2026-10-26 요청 반영
- 저장 안내를 `진행 기록은 기기 내 자동 저장됩니다.`로 통일한다. 게임 안내·더보기·일시정지·기록 화면에 같은 의미로 적용한다.
- 매일 도전 완료는 버건디 채움과 흰색 체크, 진행 중은 연한 네이비 바탕과 점, 오늘은 진한 테두리로 구분한다. 오늘이 완료 상태이면 바깥 테두리와 완료색을 함께 표시한다. 접근성 이름에도 상태를 포함한다.
- 오늘의 게임이 진행 중이면 홈과 매일 도전 상단 카드에 `이어서 풀기`와 경과 시간을 표시한다. 지난 날짜의 진행 중 도전은 달력 아래 목록에서 이어서 할 수 있다.
- 내 기록의 `진행 중인 게임` 목록에서 클래식과 날짜별 게임을 직접 이어서 한다. 보드·메모·시간·도움 사용량을 그대로 복원하고 새 실행 ID나 시작 기록을 만들지 않는다. 목록은 실제 보관 중인 미완료 게임만 포함하며 종료·중단한 과거 통계 행은 재개 대상으로 만들지 않는다.
- 완료한 날짜를 재시작하면 현재 시도는 진행 중으로 표시하고, 이전 완료 통계는 보존한다.
- 난이도 선택에는 쉬움·보통·어려움·전문가 이름만 표시한다. 선택창 하단은 `(선택한 난이도) 난이도로 새로운 문제를 시작합니다.`로 정리한다. 게임 규칙·난이도 평가·저장 형식은 유지한다.

## 한국어·영어
- 내 기록 상단 `언어` 선택에서 한국어/English를 바꾼다. 초기 기본값은 한국어다.
- [i18n.tsx](../../src/i18n.tsx)의 Provider가 `haru-sudoku:language:v1`에 `ko` 또는 `en`을 저장한다. 저장을 읽을 수 없거나 값이 지원되지 않으면 한국어로 시작한다. 언어만 바꾸며 게임 기록을 수정하지 않는다.
- 홈·달력·기록·게임·안내·접근성 이름·오류와 힌트 설명을 번역한다. 날짜 표시는 선택 언어를 따르지만 매일 도전 기준일은 계속 한국 날짜다. 문서 `lang`과 제목도 바꾼다.
- [game-messages.ts](../../src/game-messages.ts)는 상태에 보관된 한국어 원문을 표시할 때 번역한다. 단일 후보·숨은 단일 후보·후보 잠금·후보 쌍·X-Wing의 좌표·숫자·연결된 설명을 보존한다. 알 수 없는 외부 오류는 원문을 유지한다. 새 메시지나 논리 설명 템플릿을 추가할 때 번역과 테스트도 갱신한다.
- [preview.html](../../public/preview.html)은 초기 저장 언어와 프레임의 언어 변경을 반영한다. 부모 화면의 제목·설명·링크와 프레임 제목도 한국어/영어로 전환한다.
